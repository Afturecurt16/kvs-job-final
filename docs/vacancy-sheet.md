# Таблица вакансий

Источник каталога — Google Таблица, указанная в `GOOGLE_SHEETS_URL`. Заголовки находятся во второй строке; каждая вакансия занимает одну строку начиная с третьей. Сервисный аккаунт из `credentials.json` должен иметь доступ к таблице. Ключ хранится вне Git и подключается к контейнеру через `docker-compose.override.yml` или отдельный Compose-файл.

В столбцах факультетов отметьте подходящие направления значением `да`, `1`, `x` или `✓`. В поле ссылки укажите прямую страницу вакансии. Если зарплата или формат работы неизвестны, оставьте ячейку пустой: интерфейс не показывает пустые значения. Синхронизация сохраняет прежний каталог, если источник недоступен или не проходит проверку.
